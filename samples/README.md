# Sample footage (stays on this computer; not committed)

Drop real material here so Splice can be measured on it, not on synthetic clips.

    samples/
      property-1/
        raw/        <- the unedited clips for ONE listing (phone/gimbal/drone originals)
        finished/   <- the edit you made or loved for that same listing, if it exists
      property-2/ ...  (copy the same layout)
      references/   <- finished videos whose style you want to match (from Instagram, etc.)

Tips
- Originals, not Instagram downloads, for `raw/` (Instagram re-compresses and crops).
- 2 or 3 properties is plenty. More variety (interiors, exteriors, drone) is better than more of the same.
- Name things so you remember: `kitchen-walkthrough.mov`, `drone-front.mp4`, ...
- Note anything about the finished edit that matters (music, captions, pacing) in a
  `notes.txt` next to it. One or two lines is enough.
