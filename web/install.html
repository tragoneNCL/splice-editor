    First launch

    1. Start it: run splice -open (or open Splice from the Start menu on Windows). Your browser opens to the app.
    2. Mac says it can't verify the developer? That's because the app isn't signed with a paid Apple certificate yet. Right-click the file and choose Open, or run xattr -d com.apple.quarantine ~/.local/share/splice/splice. The one-line installer does this for you.
    3. Windows SmartScreen: choose More info → Run anyway.
    4. Your data: projects and footage stay on this computer. Nothing is uploaded unless you connect an AI key, and then only small preview frames are sent.
